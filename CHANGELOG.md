# Version history

## v1.3 - Five-point scoring

Correct head-to-head answers earn 5 points. Incorrect answers lose 5 points. The score display and rules reflect those values.

## v1.2 - Player pass controls

Added Q and P shortcuts so either player can pass. Once a player passes, only the other player can buzz. If both pass, the game moves to the next question without changing scores.

## v1.1 - Buzzer input fix

Pressing A or L to buzz no longer enters that letter in the answer field.

## v1.0 - Initial game

Introduced solo practice and two-player buzzer matches, with ten sample questions, answer checking, scores, and a match reset button.
